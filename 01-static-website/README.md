# Lab 01 — Static Website with Azure Blob Storage

Hands-on Azure lab covering Azure Blob Storage, static website hosting, HTML content, and website verification.

## What I did

* Created an Azure Storage account
* Enabled static website hosting
* Configured `index.html` as the default document
* Configured `404.html` as the error document
* Uploaded HTML files to the `$web` container
* Published and verified the first version of the website
* Tested the custom 404 page
* Updated the website content to a second version
* Reviewed blob properties and content type
* Deleted the temporary Azure resources after completing the lab

## Resources

* Resource group: `rg-gp-static-website`
* Storage account: `stgpstaticsite65621599`
* Container: `$web`
* Website files: `index.html`, `404.html`

## Technologies

* Microsoft Azure
* Azure Blob Storage
* Static Website Hosting
* Azure Portal
* HTML

## What I learned

This lab gave me hands-on practice with publishing static website content using Azure Blob Storage. I also practiced uploading and updating files, configuring a custom error page, and verifying the published website through its Azure endpoint.
