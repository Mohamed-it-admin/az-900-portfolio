# Lab 8 — Cloud Shell and Azure CLI

Hands-on Azure lab covering Azure Cloud Shell, Azure CLI, resource management, tagging, JMESPath queries, and resource cleanup.

## What I did

- Opened Azure Cloud Shell in Bash mode
- Verified the Azure subscription with Azure CLI
- Used the Azure CLI help system
- Listed available Azure regions
- Created a resource group from the CLI
- Created two storage accounts from the CLI
- Listed and filtered Azure resources
- Applied tags to Azure resources
- Used JMESPath queries to filter CLI output
- Compared CLI results with the Azure Portal
- Deleted the resource group from the CLI
